# JELLY BEAD — Dopamine Jewelry Store

Premium e-commerce showcase for jelly-pop Y2K futuristic jewelry.

## Stack

- **Next.js 15** (App Router)
- **Tailwind CSS 4**
- **Framer Motion**
- **Lucide React**

## Features

- Cart state management via React Context + useReducer
- 6 dopamine jewelry products with animated gradient visuals
- Interactive side-panel cart with live quantity editing
- Fake checkout with confetti celebration
- Full i18n: Russian, English, Armenian with dynamic currency

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3333](http://localhost:3333).

## Scripts

| Command       | Description          |
|---------------|----------------------|
| `npm run dev` | Start dev server     |
| `npm run build` | Production build   |
| `npm start`   | Start production     |
